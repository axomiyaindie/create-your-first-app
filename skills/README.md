## Using a skill

1. Choose a development category.
2. Open the relevant guide.
3. Give its instructions to your AI coding agent.
4. Describe the application you want to build.
5. Ask the agent to follow the guide and verify its work.

## Maturity labels

- **Guide available:** Written instructions exist.
- **Starter available:** A starter project exists.
- **Tested:** Setup and acceptance criteria have been verified.
