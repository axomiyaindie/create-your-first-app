# Agent Skills

Instruction packs that tell an AI agent (Claude, Cursor, Copilot) how to build each kind of app from scratch — no prior coding knowledge required.

## How to use
1. Open your AI agent.
2. Paste the contents of the relevant skill file, or reference it with @skills/<file>.md.
3. Tell the agent what you want to build.

## Available skills

| Skill | Use when you want to build... | File |
|---|---|---|
| Next.js app | Web app / SaaS / dashboard | build-nextjs-app.md |
| Astro site | Content site / blog / docs | build-astro-site.md |
| Flutter app | Cross-platform mobile | build-flutter-app.md |
| Android app | Native Android (Kotlin) | build-android-app.md |
| Tauri desktop | Lightweight desktop app | build-tauri-desktop.md |
| Fullstack | Frontend + backend + DB | build-fullstack-app.md |
