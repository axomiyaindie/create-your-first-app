# Create Your First App

An open-source learning and development toolkit for building real applications with AI coding agents — from your very first project to advanced AI-assisted engineering workflows.

Whether you're a complete beginner or an experienced developer, find the guides, skills, starter projects, and tools to turn ideas into working applications.

## Who is this for?

**Beginners**

Learn how applications are built, understand the development process, and use AI coding agents to create your first real project — even without prior programming experience.

**Developers**

Accelerate your workflow with reusable skills, starter projects, agent configurations, development practices, and practical resources.

## How it works

1. **Explore** — Choose a platform, technology, or learning path.
2. **Learn** — Understand the concepts and development workflow.
3. **Build** — Use starter projects and AI coding agents to create applications.
4. **Improve** — Test, debug, refine, and deploy your work.

## Project status
