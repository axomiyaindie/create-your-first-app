# Security Policy

## Supported Versions

Security updates are provided for the latest version of the project on the `main` branch.

As this project is actively evolving, older versions may not receive security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues or discussions.

Instead, use the repository's **Security** tab and select **Report a vulnerability** to submit a private report.

If private vulnerability reporting is unavailable, contact the project maintainers privately through their published GitHub contact details.

## What to Include

When reporting a vulnerability, please provide:

- A clear description of the issue.
- Steps to reproduce it, if possible.
- Potential impact and affected files or components.
- Any suggested mitigation or fix.

## Response

The maintainers will review submitted reports, investigate confirmed issues, and work toward an appropriate resolution.

Please allow reasonable time for investigation before publicly disclosing a vulnerability.

Thank you for helping keep Create Your First App and its community safe.
