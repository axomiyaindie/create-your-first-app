# Flutter Starter

Cross-platform mobile app (iOS + Android) from one Dart codebase.

## What is Flutter?
Google framework for building native mobile apps using Dart. Also supports web and desktop.

## Prerequisites
- Flutter SDK  ->  `flutter --version`
- Android Studio (for Android)
- Xcode (for iOS, macOS only)

Install Flutter: https://docs.flutter.dev/get-started/install

## Create your own copy
```bash
flutter create my_app
cd my_app
flutter run
```
