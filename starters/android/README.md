# Android Starter

Native Android app in Kotlin with Jetpack Compose.

## What is this?
Native Android development using Kotlin and Jetpack Compose (the modern UI toolkit).

## Prerequisites
- Android Studio (latest)  ->  https://developer.android.com/studio
- JDK 17+ (bundled with Android Studio)

## Create your own copy
1. Open Android Studio
2. File -> New -> New Project
3. Choose "Empty Activity" (Compose)
4. Language: Kotlin  |  Minimum SDK: API 24
5. Click Finish, wait for Gradle sync
6. Click the green Run button
