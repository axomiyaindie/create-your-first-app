# Next.js Starter

Minimal Next.js app (App Router + TypeScript + Tailwind) for web apps, dashboards, and SaaS.

## What is Next.js?
React framework for building web apps with routing, server components, and API routes built in.

## Prerequisites
- Node.js v18+  ->  `node -v`
- pnpm (or npm)  ->  `pnpm -v`

## Create your own copy
```bash
pnpm create next-app@latest my-app --ts --app --tailwind --eslint --src-dir --import-alias "@/*"
cd my-app
pnpm dev
```
Open http://localhost:3000
