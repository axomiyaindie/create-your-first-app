# Application Starter Kits

Choose a starting point, customize it, and build your application.

These starter kits are organized by the type of application you want to create.

## Browse starter categories

| Category | Technologies |
|---|---|
| [Web](web/README.md) | Next.js, Astro |
| [Mobile](mobile/README.md) | Flutter, Android, iOS |
| [Desktop](desktop/README.md) | Tauri, macOS, Linux |
| [Backend](backend/README.md) | Node.js, Express, Python, FastAPI |
| [Full-stack](fullstack/README.md) | Next.js, Prisma |

## Understanding availability

- Guide available: instructions exist.
- Starter available: actual project source code is included.
- Tested: setup and documented acceptance criteria have been verified.

Not every technology directory currently contains a runnable project.
Check its README before starting.
