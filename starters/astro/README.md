# Astro Starter

Minimal Astro site for blogs, docs, landing pages, and content sites.

## What is Astro?
Static-site framework that ships zero JavaScript by default. Great for blogs and docs.

## Prerequisites
- Node.js v18+  ->  `node -v`
- pnpm (or npm)  ->  `pnpm -v`

## Create your own copy
```bash
pnpm create astro@latest my-site
cd my-site
pnpm dev
```
Open http://localhost:4321
